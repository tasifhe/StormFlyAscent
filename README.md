# StormFly Ascent

> **Survive a deadly, procedurally generated storm on a tilt-controlled hoverboard.**

StormFly Ascent is an infinite runner survival game built in Unity. Players pilot a high-speed hoverboard through a treacherous, never-ending storm, dodging dynamic obstacles and navigating procedural environments.

---

## 🎮 Key Features

*   **Procedural Level Generation:** No two runs are the same. The game generates level segments and obstacle patterns on the fly using advanced spline-based pathing.
*   **Dual Control Schemes:** 
    *   **Gyro/Tilt Controls:** Immerse yourself by physically tilting your device to steer (Mobile).
    *   **Touch Joystick:** Precision control for casual play or difficult maneuvers.
*   **Dynamic Difficulty:** The storm intensifies as you survive longer. Obstacle density and complexity scale with your playtime.
*   **Diverse Obstacles:** Dodge static barriers, moving hazards, and oscillating rings.
*   **Customization:** (In Progress) Settings to fine-tune sensitivity, audio, and graphics quality.

## 🕹️ Controls

### Mobile
*   **Steer:** Tilt device (Gyroscope) OR Use On-screen Joystick.
*   **Navigate UI:** Touch interaction.

### Desktop / Editor
*   **Steer:** WASD or Arrow Keys.
*   **Debug:** Mouse to simulate touch input.

## 🛠️ Technical Overview

Built with **Unity**, leveraging professional packages for robust performance:

*   **Dreamteck Splines & Forever:** Powers the infinite procedural path generation and smooth object movement along splines.
*   **Animancer:** innovative animation system for fluid character states.
*   **Input System:** Supports multi-platform input (Touch, Gyro, Keyboard).

## 🚀 Installation & Setup

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/yourusername/StormFlyAscent.git
    ```
2.  **Open in Unity:**
    *   Launch Unity Hub.
    *   Click "Add" and select the `StormFlyAscent` folder.
    *   Open the project (Recommended Unity Version: 6000.0.x or latest stable).
3.  **Play:**
    *   Open the default scene (typically in `Assets/_Scenes`).
    *   Press **Play** in the editor.
